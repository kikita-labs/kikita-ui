# i18n

Present only because this project opted into i18n. Delete this file (and its `AGENTS.md`
link) if that questionnaire answer was "no".

Approach: Transloco with HTTP-loaded JSON catalogues in `public/i18n/` and runtime language switching.

- Locale catalogues contain the language that users read. English-only repository rules do not
  apply to values in `public/i18n/*.json`; source code, tests, and documentation remain English.
- Read [i18n-json-architecture.md](./i18n-json-architecture.md) before adding a key, language,
  scope, loader, or validation rule.

- No hardcoded user-facing strings in templates or components. Every string a user sees
  goes through the chosen i18n mechanism.
- Keys/messages are named by feature and purpose (`user.card.title`), not by their English
  text.
- Date, number, and currency formatting always goes through Angular's locale-aware pipes
  (`DatePipe`, `DecimalPipe`, `CurrencyPipe`) or the runtime library's equivalent — never
  hand-rolled formatting.
- New locales get added to the build config and to this file's approach note, not silently.

## Kikita UI messages and locale

The library's own text (accessible names, visible words, placeholders) is a Kikita UI concern, not a
page concern: do not pass `ariaLabel`-style inputs just to translate a built-in label.

- `provideKikitaUi({ locale, messages })` in `app.config.ts` reads both from the active Transloco
  language (`kui-i18n-sources.ts`): `locale` through `KUI_LOCALE_BY_LANGUAGE`, `messages` from the
  `kui` subtree of the catalogue, converted by `createKuiMessagesLayer`
  (`src/app/shared/utilities/kui-messages/`).
- The `kui` subtree of `public/i18n/en.json` and `ru.json` holds exactly the library keys, grouped
  like `KuiMessages` (`kui.pagination.next`). A value is a template with `{name}` placeholders, or an
  object with `$select` naming the parameter that chooses a variant: plural categories for a number
  (`one`, `few`, `many`, `other`), `true` and `false` for a boolean. Keep the same placeholders in
  both languages. `pnpm audit:static` fails when a library message is missing or unknown.
- When the library adds a message, add its key to both catalogues in the same change.
- A page example that shows a custom label (a documented `ariaLabel` input) keeps its own page-scope
  key; only library defaults live under `kui`.
