# Time Picker Contract Inventory

Accepted at the Plan 10.2 research gate and implemented from this map. The source audit covered against `docs/time-picker.md`, the directive, panel, affix, format utility, stylesheet, unit specs, the field integration, the legacy page (scenarios only) and the known-defect record.

The component is two public pieces used together: `input[kuiTimePicker]` (`KuiTimePickerDirective`) and `kui-time-picker-panel` (`KuiTimePickerPanelComponent`) inside a sibling `kui-dropdown` in the same `kui-field`. The panel also works standalone. `KuiTimePickerInputAffixComponent` is internal chrome (clock icon, clear button, chevron button).

## Panel: inputs and behavior

Every panel member is a `model()` (`value`, `format`, `hourStep`, `minuteStep`, `secondStep`, `showSeconds`, `minTime`, `maxTime`, `disabledHours`, `disabledMinutes`, `disabledSeconds`). Inside a `kui-field` the directive pushes them, so the default examples bind nothing on the panel. Only the standalone use binds `value` and `showSeconds` directly.

- Columns: `role="listbox"` with `aria-label` "Hours", "Minutes", "Seconds", `tabindex="0"`; cells `role="option"`, `aria-selected`, `aria-disabled`.
- Selected cell is a filled cell; a click or arrow pick does not close the panel.
- Column keyboard: ArrowUp/ArrowDown cyclic, skipping disabled cells; Home/End first/last enabled; Enter closes the dropdown.
- AM/PM: `kui-segmented` radiogroup (`aria-label` "AM/PM") only in 12h. The period is derived from the value's hours (AM when empty). Choosing the current period is a no-op; the other period shifts hours by 12.
- Footer: "Now" sets the current time (clamped only into min/max, minute and second snapped to steps, seconds only with `showSeconds`); "Done" closes the dropdown.
- Centering: every column scrolls its selected cell to the middle on open (deferred one task after the dropdown's `isOpen`) and after each value change. Skipped during SSR.
- Chrome: with a `kui-dropdown` ancestor `data-kui-flat` drops its own background and border; standalone it draws them.
- Empty value base is today at local midnight (not the wall-clock hour).

## Discrepancies and findings

1. Docs claim `Escape` "anywhere in the field ... focus stays in the field". Implementation: Escape typed in the input keeps focus; Escape after ArrowDown moved focus into the Hours column used to leave focus on `<body>`; fixed in Plan 10.3 (`kui-dropdown` returns focus to the field control), and the check is now a normal test.
2. Docs describe every panel wiring input as push-only, but the panel exposes them as `model()`, so two-way binding on the panel is technically possible. The page does not use it beyond standalone `value`.
3. The panel class JSDoc says `@internal` while it is exported from the package barrel and documented as public. The Kikita UI MCP has no `time-picker` component slug (`get_kikita_component` returns "Unknown component slug"), so the docs file was the contract source.
4. Docs "a fully typed value is never out of range" does not hold for a 12h hour of `00`: the mask clamps only the upper bound, `parseDisplayTime` returns `null`, and the field becomes `aria-invalid` without committing. Verified in the browser on this page: typing `0030` in the 12-hour picker leaves `00:30` in the field with `aria-invalid="true"` and the previous value uncommitted (the panel keeps the earlier selection); `0130` commits `01:30 PM`. Recorded as an observed edge case, covered by a browser test, not claimed as a defect.
5. Typed 12h text without AM/PM defaults the period from `this.value() ?? new Date()`, so an empty field's default period depends on the wall clock, while the panel and "Now" use midnight or the real clock. The page therefore fixes time with `page.clock.setFixedTime` in every spec. Clearing the text (`fill('')`) does not clear the value: only the Clear button does, so a typed 12-hour value after emptying the text keeps the previous period.
6. `disabledHours`, `disabledSeconds`, `maxTime`, `clearable`, `readonly`, Signal Forms and the "Now" button through the directive have no directive unit coverage (unit specs cover min/max on the panel, `disabledMinutes`, typing, clear, disabled/readonly open guard, Done, seconds column). The page and browser spec provide that evidence.
7. `--kui-timepicker-suffix-gap` is read by the stylesheet with a `2px` fallback but was missing from the docs token table; the row is added to `docs/time-picker.md` in the same commit.
8. Library-owned strings are hard-coded English: Hours, Minutes, Seconds, AM/PM, Now, Done, Clear, Open time picker, Close time picker. Page labels are localized; these stay English in RU, as on other pages.
9. Docs known gaps still apply: `aria-controls` is absent until the panel exists; "Now" ignores `disabledHours/Minutes/Seconds`; no range picking; no locale-aware format; the clock icon is a static glyph.
10. Field `required` is exposed to assistive technology as `aria-required` on the control (Plan 19B, 2026-10-03). The Field `required` state is covered on the Field page and in `field/kui-field-control-wiring.spec.ts`.

## Page (cards, each a `role="group"` with a translated `aria-label`)

Fixed values use local `new Date(2026, 4, 14, h, m, s)`. Browser tests pin the clock with `page.clock.setFixedTime` (UTC).

1. Default: empty 24h picker, label "Meeting time".
2. Formats: 24h `14:30`, 24h with seconds `14:30:45`, 12h `02:30 PM`, 12h with seconds `09:05:30 AM`.
3. Steps: 12h + seconds + minute/second step 15 (docs example); 24h with hour step 3 and minute step 15.
4. Bounds: min 09:00 / max 18:00; disabled hour 12; disabled first 15 minutes of every hour; disabled seconds 0-14 with seconds.
5. Field states: clearable inherited from a provider that disables it, local clearable true overriding it, disabled, readonly, custom placeholder.
6. Field wiring: hint + required marker; typed-invalid example (hint tells to type `12:3`).
7. Sizes: `kui-field[size]` xs, sm, md, lg (size cascades from the field).
8. Signal Forms: `[formField]` with `required()` and a `kuiError` message after touch, recovering after a pick.
9. Inline panel: standalone `kui-time-picker-panel [(value)] showSeconds` with no dropdown.

One page-private component per card under `components/` (Signal Forms owns its schema, model, and default state; Bounds owns its blocked-quarter constant), a layout-only `time-picker-grid.scss` shared by the card components, and a page-level `helpers/createPickerTime` that builds fixed seed values. Locale scope `time-picker` (alias `timePicker`), sidebar key `playground.components.timePicker`.
