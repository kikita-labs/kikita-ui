# Scrollbar Example Inventory

Scrollbar is a native CSS styling utility and root provider option, not an Angular component.
This page exercises the existing contract through real overflow containers.

| Contract surface                            | Source-backed behavior                                                                                                                                                                                                                                                                                                                                                                                                                                  | Visible or browser coverage                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| ------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `.kui-scroll`                               | Applies scrollbar styling to the element that owns overflow; it does not create overflow or add JavaScript behavior.                                                                                                                                                                                                                                                                                                                                    | The vertical list and both theme examples use the class on their focusable scroll regions.                                                                                                                                                                                                                                                                                                                                                                                                          |
| `provideKikitaUi({ scrollbars: 'styled' })` | Sets `data-kui-scrollbars="styled"` on the document root in the browser; the current Playground app already configures this mode.                                                                                                                                                                                                                                                                                                                       | The wide table deliberately has no `.kui-scroll` class. E2E checks the root attribute and its computed scrollbar style. The page has no provider toggle.                                                                                                                                                                                                                                                                                                                                            |
| Provider values                             | `scrollbars` is optional and accepts `'native'` or `'styled'`. Explicit `'native'` removes the root attribute; an omitted option leaves an existing value alone. Fresh applications use native browser styling for application-owned scrollers by default.                                                                                                                                                                                              | The page renders the configured Playground mode. Provider unit tests cover `'native'`, `'styled'`, and omitted configuration; neither provider state is re-created as a page control.                                                                                                                                                                                                                                                                                                               |
| Kikita-owned scroll areas                   | Dropdown, command palette, dialog body, and drawer body have built-in styling independent of the global option.                                                                                                                                                                                                                                                                                                                                         | Omitted from this page to keep it focused on consumer-owned native overflow; their component pages exercise those components.                                                                                                                                                                                                                                                                                                                                                                       |
| Axis and overflow                           | Scroll direction follows native `overflow` and content dimensions.                                                                                                                                                                                                                                                                                                                                                                                      | Vertical list plus a table with both horizontal and vertical overflow; keyboard tests verify `PageDown` and `ArrowRight` scroll the focused regions.                                                                                                                                                                                                                                                                                                                                                |
| Touch                                       | Touch scrolling remains native browser behavior; the utility does not add gesture handling.                                                                                                                                                                                                                                                                                                                                                             | No synthetic swipe state is added. Mobile captures verify the layout at 320px while scrolling stays browser-owned.                                                                                                                                                                                                                                                                                                                                                                                  |
| CSS variable contract                       | `--kui-scrollbar-size`, `--kui-scrollbar-radius`, `--kui-scrollbar-track`, `--kui-scrollbar-thumb-min`, `--kui-scrollbar-thumb-inset`, `--kui-color-scrollbar-thumb`, `--kui-color-scrollbar-thumb-hover`, and `--kui-color-scrollbar-thumb-active` customize native scrollbar geometry and thumb colors. Theme defaults are 10px size, 32px minimum thumb, 2px inset, full radius, transparent track; light and dark themes use distinct thumb colors. | Screenshots show the light/dark contexts and responsive dimensions. E2E compares the resolved light/dark thumb color tokens, checks `scrollbar-width: thin`, and verifies the forced-colors fallback. The Chromium runner launches with `--hide-scrollbars`, so tracks and thumbs are not visible in captures. Geometry remains at theme defaults; per-token overrides are omitted because native scrollbar rendering differs by browser and OS. Hover/active colors are recorded separately below. |
| Hover and active                            | The stylesheet defines WebKit thumb hover/active pseudo-states. Appearance is browser and OS dependent.                                                                                                                                                                                                                                                                                                                                                 | No static illustrations. Real native scrollbar hover/drag screenshots are omitted because the scrollbar UI may be overlaid or rendered differently by the platform.                                                                                                                                                                                                                                                                                                                                 |
| Forced colors                               | The stylesheet restores `scrollbar-color: auto` for forced-colors mode.                                                                                                                                                                                                                                                                                                                                                                                 | Browser assertion checks the forced-colors computed value; no separate visual variant is shown.                                                                                                                                                                                                                                                                                                                                                                                                     |
| Accessibility                               | These remain native scroll containers. The scrollable element needs `tabindex="0"` to receive keyboard scrolling; no ARIA role is needed to style it.                                                                                                                                                                                                                                                                                                   | Each example is a named `region` with `tabindex="0"`; E2E focuses and scrolls the vertical and table regions.                                                                                                                                                                                                                                                                                                                                                                                       |
| SSR                                         | The provider sets the root attribute only when `isPlatformBrowser` is true. The page template itself has no browser API use.                                                                                                                                                                                                                                                                                                                            | Page E2E asserts raw server HTML omits the browser-only root attribute and that hydration applies it without runtime or console errors. The shared route sweep also checks the route heading at SSR and after navigation.                                                                                                                                                                                                                                                                           |
| Public inputs, outputs, models              | Scrollbar has none. No page component API is added.                                                                                                                                                                                                                                                                                                                                                                                                     | Not applicable.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |

The local `.kui-scroll` example shows the class on its actual overflow owner, but its visual effect cannot be isolated from the Playground's globally styled root on this route. The provider's `'native'` mode cannot be contrasted against `'styled'` here for the same reason. The documented experimental custom-track proposal is not implemented or represented here.

- [x] Overflow is owned by each actual native scroll container; styles use Kikita tokens for layout and dimensions.
- [x] Hover/active are not drawn as false static states; no custom scrollbar or provider toggle is presented.
- [x] EN/RU labels and content use a matching scoped translation structure.
